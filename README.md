# Quantivo v4.0.0 — web interface

Upload the contents of this folder, including `assets`, to the publishing root
of the existing GitHub Pages repository for the guest preview. No build step.
`index.html` must be in the root, not inside an extra folder.

For real accounts, run the server included in the full package. It serves this
interface and the API from the same origin. GitHub Pages cannot run Python.
Forms are disabled when the service is unavailable and offer guest access.
No fake local accounts or locally stored passwords are created.
